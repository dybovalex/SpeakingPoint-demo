Foundations

The SpeakingPoint design system

One token set drives every screen in this prototype — and maps straight into tailwind.config.js for the real Next.js build. Component shapes follow the Tailwind Plus application-UI vocabulary; the palette and type are ours.

01 — Colour

Palette

Anchored on Toastmasters' own blue and gold. The timing-light triad — green, amber, red — is the semantic system every member already reads: attendance state, role status, and speech timing all speak the same three colours.

05 — Handoff

Straight into Tailwind

These tokens aren't decoration — they're the config for the real build. Paste into theme.extend; the component classes above become @apply recipes or the paid template's equivalents.

// tailwind.config.js — theme.extend
colors: {
  primary: { DEFAULT:'#0B4F6C', strong:'#083F58', tint:'#E6F0F5' },
  gold:    { DEFAULT:'#B7810A', tint:'#F6EEDA' },
  // timing-light triad = semantic status
  go:      { DEFAULT:'#1E874B', tint:'#E3F1E9' },
  wait:    { DEFAULT:'#B9750A', tint:'#F6EEDD' },
  stop:    { DEFAULT:'#B0242B', tint:'#F6E4E4' },
  ink:'#0F2028', ground:'#F5F8FA', line:'#E1E8EC',
},
borderRadius: { sm:'6px', md:'8px', lg:'12px', xl:'16px', '2xl':'22px' },
fontFamily: {
  sans: ['"Plus Jakarta Sans"', 'system-ui', 'sans-serif'],
  mono: ['"JetBrains Mono"', 'ui-monospace', 'monospace'],
},

Member · the weekly action

One screen, the whole evening

Open the meeting, say if you're coming, take a role — in seconds. easy-Speak makes members pinch-zoom a desktop table; here the same actions are native to whichever screen you're on.

Built for the phone in your hand

  • Attendance in one tap — Coming, Can't, or No answer, changeable until the meeting starts.
  • Open roles stand out in amber. Tap one to see what it involves and take it.
  • Real Toastmasters roles — Toastmaster, Timer, Grammarian, Ah-Counter, Table Topics — named exactly as your club says them.

Public · no account

The one thing a visitor will actually try

A skeptical guest won't make an account. This is the single public page they touch — name, email, done. The club gets an email; the guest never sees member data or the agenda.

Register a visit in 15 seconds

The only public surface besides the membership form. It writes one guest visit and emails the club's power user — nothing more.

  • No password, no confirmation link. Two fields and a button.
  • Spam-protected with a honeypot field — invisible here, matching the tech spec (TR-04).
  • A gentle nudge toward membership on success — never a wall.
